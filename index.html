SOBRE EL PROYECTO

Más que automóviles, una pasión.

AutoDrive es un proyecto web creado para presentar información relacionada con el mundo automotriz mediante una interfaz moderna, atractiva y fácil de utilizar.

El proyecto integra tecnologías de desarrollo web como HTML, CSS y JavaScript, además de utilizar herramientas de control de versiones para gestionar los cambios realizados durante su desarrollo.
